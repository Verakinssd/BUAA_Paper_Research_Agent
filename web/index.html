A LITTLE FIELD GUIDE
开始你的第一次研究

      

        
1
提出一个具体问题
写下研究主题、关注的方法或希望比较的方向，再选择需要的论文数量。

        
2
连接模型，开始研究
确认本地模型已连接，点击开始研究。Agent 会检索 arXiv 与 OpenAlex，筛选论文并阅读全文。

        
3
查看论文与研究报告
查看论文入选理由、全文总结及来源，完成后可导出 Markdown 研究报告。来源限流或 PDF 不可获取时，会显示实际失败情况。

        
模型状态可在左下角查看。管理员可在工作台切换可用模型；模型就绪后即可开始研究。

        
快捷操作：Ctrl / ⌘ + Enter 开始研究，N 新建研究。
